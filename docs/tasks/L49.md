## Results

(claude-6, 2026-10-12; branch `task/L49`)

**Census.** Of the 160 functions that were neither verified nor thunks on
native-L49:
- 130 lift but have no fixture (the recorder lane);
- 15 are verification gaps;
- 12 are code inside other lifted bodies;
- 3 are lift rejections.

**Fragments (rule, 11 credited).** Some inventory entries are code inside
lifted bodies: case labels, or a frame tail whose whole body lies inside
its owners'. Examples: 0x00561239, 0x0057D24D, 0x00B5A6BF, 0x01300749.
- `lift.fragments` finds them.
- gen writes `patterns/fragments.json` (entry, owners, evidence: "frame
  tail" or "no callers").
- `inventory.py` credits an entry once every owner is verified.
- 16 found; 11 not yet verified, all with verified owners.

**Boundary.** 0x00736370 is a switch's case table: three code addresses,
read past the end of rAIPresetCharaInfo's vtable. Discovery
(`code_entry`) now rejects a candidate whose first three dwords are code
addresses within 64 KB. It was the only such admission of 8,962. It leaves
the inventory at the next discovery run.

**Recorder flag guard (3 recorded).** The recorder rejected `div; inc edx`
as a read of the undefined CF. INC and DEC carry CF over without reading it
(Intel SDM). The Rust side already does this (`Flags::inc_dec`, L46). The
guard now carries CF's validity over instead; a later reader is still
rejected (unit tests for both).
- Recorded 3/3 and adopted: 0x005524B0, 0x00604A80, 0x00C9B350.
- Left to Codex, input problems: 0x00BA4160 (its closed callees run to
  0x00000CD7) and 0x00D29AF0.

**x87 interior helpers: `caller-state-v1` (3 recorded).** The CRT x87
error handlers (0x01304753, 0x0130474C, 0x01300617) run in their caller's
frame.
- **The cause:** 0x01304753 loads the control word its caller stored with
  `fnstcw [ebp - 0xa4]`. Random frame bytes stood in for that value, and
  the recorder rejected the exceptions they unmasked. That guard is right:
  the Rust x87 model runs on the host FPU and asserts a masked control word.
- **The new input:** `caller_state.py` replays a verified caller's
  accepted case exactly, checking every recorded field as
  `constructed_inputs.construct` does, up to its mocked call to the
  helper. The pages, heap cursor, registers and ESP there start the
  helper.
- **Harness hooks:** `run_sparse(capture_call=)` and an `esp` in
  `initial_state`. The vector protocol is unchanged, and each case records
  its provenance (`construction`, rule `caller-state-v1`).
- **Recorded 3/3 each from several callers.** 0x01304753 from 0x01304690
  and 0x013046CE; 0x0130474C from 0x0130470B and 0x0130489A; 0x01300617
  from 0x012F0708, 0x013296A8 and 0x0132992D. The cases read the stored
  control word, 0x037F.
- **Not recorded:** 0x01300600, which no verified case reaches.

**Verification gaps: 16 to 5 (11 closed).** New rules in the edge proof,
each with unit tests (positive and negative):
- **Callers' bounds.** A register that is an input of the function is
  bounded by every direct branch to the entry (call, jmp or jcc; rel32 or
  rel8), using the same rules in each caller's decoded body. The rule
  needs the address to appear nowhere in the image as a dword. A caller's
  own inputs stay unbounded inside the proof, so the result does not
  depend on lifting order.
  - Registers: 0x004593E0, 0x004594A0, 0x0044D1F0, 0x005F3C70.
  - Stack arguments: 0x009C4230, `[esp + 4]` pushed after
    `cmp eax, 8; ja`.
- **Compare of a copy.** `mov eax, esi; cmp esi, 6; ja` (0x00FA0130), and
  a register loaded from the slot before the compare, with conditional
  exits between them (0x00CC0F10).
- **Equal edges.** On the `je`-taken or `jne`-fall-through edge, an ALU
  result or `test R, R` gives R = 0, and `cmp R, imm` gives R = imm
  (0x00711200).
- **`lea R, [R2 + d]`:** R2's bound shifted by d.
- **esp-relative slots** across `push`, `pop` and `add`/`sub esp, imm`; a
  push into the slot gives it the pushed value.
- **Wider compare window.** A compare may sit up to 24 instructions before
  its branch: 0x0097A6A0 has ten stores between them; 0x004298B0 too.
- **0x0059C1A0** is proven by these rules as well.

Footprint over all 2,199 lifted records with a table jump:
- 27 tables gain a proof, none loses one; unproven tables go from 31 to 4.
- Decoding those 2,199 records takes 33 s instead of 23 s.
- One body changes. In 0x00BC1A00, L48 bounded `eax` by `and ebx, 0xff`
  (slots 0..255) and decoded the dwords after the table as targets, the
  bogus 0x0104C481 and 0x0104EC81. The compare of the copy now gives the
  true 0..16, which ends at the 0xCCCCCCCC padding. The new body is a
  subset of the record's, so the record is not stale and stays as it is.
- Tables L48 credited by slot sweep (D) are now also proven; for example
  0x00441FB0, 0x007671E0, 0x00A48B70.

**The 5 remaining gaps:**
- **0x009921E0 and 0x00A2F3B0.** The index is a frame slot (`[esp + 0x18]`;
  the argument `[ebp + 0xc]`) loaded after calls. Both functions pass
  other frame addresses (`lea ecx, [esp + 0x44]`) to callees. Proving that
  a callee cannot write the slot rests on the C++ object model: a pointer
  to one local never reaches another. That is the head's call.
- **0x012E7CE0** switches on a struct field (`[ecx + 0x10]`) with no check
  in the code.
- **0x00565308 and 0x00786D69** have stale bodies (inlined frame tails
  since L46). A refresh failed: the new tail code runs through an input
  pointer ("execution outside the image"). That is the input lane.

**x87 mocks: a proposal, not changed (board #9702).** 0x009897C0,
0x00F83C00 and 0x013156B0 fail for one reason: a mocked call never pops
its callee's x87 arguments.
- 0x009897C0 loops through `_CIfmod` (0x012F4E6A): at run time the stack
  fills one value per pass and faults at 0x009899D0.
- 0x00F83C00 calls `_CIfmod` seven times in a row.
- 0x013156B0 loops over `_ftol2` (0x012F05C0).

Each callee's entry contract is proven from its code (`x87_deficit`; for
example `_ftol2`: entry 1, exit 0). The proposal is for the mock to pop
that contract, push only where `returns_float` proves a result (as now),
and record `st_pop` for the replay handlers. Vectors without `st_pop`
replay unchanged. 163 lifted functions (330 call sites) would get the new
model at gen and need a refresh.

Separately, `x87_depth_check` stops when it revisits an instruction at a
greater depth. That is sound for underflow but not for overflow; it is how
0x009897C0's loop passed statically.
