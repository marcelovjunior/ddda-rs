## Results

(claude-6; branch `task/L58`)

**Rule (`discover_functions.record_tables`).** Starting at a referenced
address in data, the rule reads records of 2 to 8 dwords.
- Each field holds a code pointer, a NULL or a small integer (< 0x10000),
  and keeps one kind across the records; a NULL fits either kind.
- At least one field holds pointers, and one holds a nonzero integer. A
  plain pointer run is left to `callback_tables`.
- The records stop where a field changes kind, and the smallest
  consistent stride is taken.
- The member checks are L54's: a known member, and every other pointer at
  a function boundary, inside no known function and not text-like, or
  nothing is admitted.

The referenced-address set is now computed once per discovery run.

**Found (8):** the seven getters 0x0112BB20, 0x0112BB40, 0x0112BB60,
0x0112BB80, 0x0112BBA0, 0x0112BBC0 and 0x0112BBE0 (0x01441CF0, 15 records
of 12 bytes; 0x0112BC00 was L54's), and 0x00718470 (0x015164B8: records
of {id, id, id, handler}, 16 bytes). All eight record 3/3 (small-v1).

**Also new:** 0x0065AFF0 and 0x0065B020, address-taken entries named by
code that L54's new records lifted. Both record 3/3.

**0x012F4E74:** no static rule reaches it. Its `_CI` descriptor (base
0x01455D30, referenced) holds 15 more pointers, and none is a known entry
or a function boundary: they are interior labels of the CRT error code.
Its admission stays L54's runtime evidence.

**Recorder guard (head #9879).** `structured_inputs.prepare` skips any
entry that `lift.inlined_tail` classes as its jumpers' code, with the
reason recorded (41 set aside on native-L58). With this lifter
0x012F693F, 0x012F6A6F and 0x01300DFF are not tails: no jumper state, and
their jumpers tail-call them.
